# Arbri Jesku - Personal Website

This is a multi-page personal academic website for GitHub Pages.

## How to edit

- Open the corresponding page to edit each section:
  - `index.html` - Home
  - `education.html` - Education
  - `experience.html` - Experience
  - `projects.html` - Research Projects
  - `publications.html` - Publications
  - `skills.html` - Skills
  - `contact.html` - Contact
- Open `style.css` to change colors, fonts, spacing and layout.
- Replace `profile.png` to update the profile photograph.
- `script.js` controls the page transition and loading effect.
- Search for `href="#"` in the project and publication pages and replace each `#` with the correct URL.
- Duplicate the marked project or publication blocks to add new entries.

## How to publish on GitHub

1. Open the `arbri-jesku.github.io` repository.
2. Select **Add file > Upload files**.
3. Upload all files from this folder directly to the repository root. Do not upload the parent folder itself.
4. Commit the changes to the `main` branch.
5. Wait a few minutes and visit `https://arbri-jesku.github.io`.
