# Arbri Jesku - Personal Website

This is a static personal academic website for GitHub Pages.

## How to edit

- Open `index.html` to edit the text, links and sections.
- Open `style.css` to change colors, fonts, spacing and layout.
- Replace `assets/profile.png` to update the profile photograph.
- Search for `href="#"` in `index.html` and replace each `#` with the correct URL.
- Duplicate the marked project or publication blocks to add new entries.

## How to publish on GitHub

1. Open the `arbri-jesku.github.io` repository.
2. Select **Add file > Upload files**.
3. Upload `index.html`, `style.css` and the `assets` folder.
4. Commit the changes to the `main` branch.
5. Wait a few minutes and visit `https://arbri-jesku.github.io`.
